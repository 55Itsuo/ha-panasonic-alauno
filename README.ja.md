# Home Assistant 用 Panasonic アラウーノ連携

[English](README.md)

パナソニック製トイレ「アラウーノ」を Home Assistant で扱うための**非公式**カスタム統合です（S160 タイプ1K、型番 `CH1601WSSK` で動作確認）。スマホアプリが表示しているクラウド上のデータを読み取ります。

> **免責**: 本プロジェクトはパナソニックとは無関係で、公認・サポートを受けたものではありません。アプリの非公開クラウドAPIを利用しているため、予告なく変更・停止する可能性があります。自分のアカウント・自分の機器にのみ、自己責任でご利用ください。適用される利用規約もご確認ください。

## 機能

選択したトイレごとにデバイスが作られ、次のエンティティが追加されます（通常1台あたり6つ。お手入れ系の項目は、機種ごとにクラウドが返す内容によって変わります）。

| エンティティ | 種別 | 内容 |
|---|---|---|
| 最終使用 | センサー（時刻） | 直近の使用時刻 |
| 今日の使用回数 | センサー | 本日の使用回数 |
| 洗剤タンク お手入れ | バイナリセンサー（問題） | 洗剤の補充が必要 |
| 脱臭フィルター お手入れ | バイナリセンサー（問題） | 脱臭フィルターの交換が必要 |
| 洗浄ノズル お手入れ | バイナリセンサー（問題） | ノズルのお手入れ・交換が必要 |
| リモコン電池 お手入れ | バイナリセンサー（問題） | リモコン電池の残量低下 |

エンティティ名は Home Assistant の言語設定（日本語／英語）に従って表示されます。

お手入れ系のセンサーには `level`、`first_notified_date`、`last_cared_date`、`howto_url` などの属性があります。

クラウドから5分ごとに取得します（リアルタイムではありません）。

## 対応していないこと

トイレ本体にはローカルAPIがなく（TCPポートは閉じており、ECHONET Lite にも応答しません）、パナソニックのクラウドに依存します。電気・水の月次レポートは**取得できません**。この機種ではアラウーノアプリでも選択できない機能で、クラウド側に関連する仕組みの痕跡はあるものの、実際には利用できないためです。

## インストール

### HACS（カスタムリポジトリ）

1. HACS → 右上の︙ → **カスタムリポジトリ**
2. このリポジトリのURLを、カテゴリ **Integration** で追加
3. 「Panasonic Alauno」をインストールして Home Assistant を再起動

### 手動

`custom_components/alauno` を Home Assistant の `config/custom_components/` にコピーして再起動します。

## セットアップ

1. **設定 → デバイスとサービス → 統合を追加 → Panasonic Alauno**
2. ダイアログのログインリンクは、クリックせずに**右クリックしてコピー**します。シークレットウィンドウを開き、開発者ツール（Network タブ）を**先に開いてから**リンクを貼り付け、CLUB Panasonic ID でログインします。
3. ログイン後、ブラウザは `com.panasonic.jp.kbsbu.alauno://...` で始まるURLを開こうとします。ブラウザでは開けませんが、Network タブに `callback?code=...` のリクエストが赤く表示されます。そのURL全体（または `code` の値だけ）をダイアログに貼り付けます。コードは約1分で失効するので、すぐに貼ってください。
4. アプリが通信時に送る `x-api-key` を入力します。この値はアプリ固有で、このリポジトリには**含まれていません**。各自で入手してください。
5. 取り込むトイレを選びます。

> **注意**: 設定後はスマホのアラウーノアプリでログアウトしないでください。ログアウトするとこの統合のトークンも無効になり、統合を削除して再追加する必要があります。

## 既知の制限

- 再認証フローは未実装です。トークンが失効したら統合を削除して再追加してください。
- 5分間隔のポーリングです。
- 非公式APIのため、予告なく仕様が変わることがあります。
- 動作確認は上記の型番と Home Assistant 2026.10 のみです。
